# MOTO 24H – FIT4014 A3
Website cửa hàng xe máy mô phỏng. Mở index.html bằng Chrome hoặc dùng Live Server. HTML5/CSS3/JavaScript thuần, không cần cài thư viện.

## Demo https://github.com/duongsytien/MO_PHONG_MOTO_FIT404.git
- Lọc loại xe, tìm kiếm, sắp xếp giá, xem chi tiết và thêm/bỏ quan tâm.
- Đăng nhập bằng demo@moto24h.example / Moto24h@123; đăng xuất qua nút Tài khoản.
- Xem và thêm đánh giá trong phiên trang.
- Responsive cho màn hình rộng/hẹp.

## GitHub Pages
Tạo repository công khai, đưa index.html, style.css, app.js và các tài liệu lên nhánh main ở thư mục gốc. Settings > Pages > Deploy from a branch > main / (root) > Save. Kiểm tra URL do GitHub cấp và ghi commit thực tế vào báo cáo. Chưa triển khai công khai.

## Giới hạn
Giá, thông số, địa chỉ, hotline, đánh giá và hình minh họa không phải dữ liệu bán hàng xác minh. Email .example không hoạt động. Đăng nhập chỉ so khớp thông tin mẫu ở trình duyệt, không có backend, không bảo mật tài khoản thật. Không lưu mật khẩu hoặc gửi dữ liệu; trạng thái mất khi tải lại trang. Không thanh toán hay đặt hàng thật. Hình SVG tự tạo, không phải ảnh chính thức.
